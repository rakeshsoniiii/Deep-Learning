## Overview

This repository provides a structured learning path for deep learning concepts, architectures, and implementations. It contains practical examples and tutorials for both TensorFlow and PyTorch frameworks, organized from foundational concepts to advanced architectures.

---

## Learning Path

### Level 1: Foundations

#### Traditional Machine Learning
- **Perceptron** - Basic neural network unit
- **Logistic Regression** - Binary classification fundamentals
- **Softmax Regression** - Multi-class classification

#### Multilayer Perceptrons (MLP)
- **Basic MLP** - Deep feedforward networks
- **MLP with Dropout** - Regularization techniques
- **MLP with Batch Normalization** - Training optimization
- **MLP from Scratch** - Understanding backpropagation

---

### Level 2: Computer Vision

#### Convolutional Neural Networks (CNN)
- **Basic CNN** - Convolutional layers fundamentals
- **CNN with He Initialization** - Weight initialization strategies
- **Fully Convolutional Networks** - Architecture concepts

#### Classic Architectures
- **LeNet-5** - Pioneering CNN architecture
- **AlexNet** - Deep learning breakthrough
- **VGG Networks** - Depth and simplicity
- **ResNet Family** - Residual connections and skip connections
- **DenseNet** - Dense connectivity patterns
- **MobileNet** - Efficient mobile architectures
- **Network in Network** - 1×1 convolutions

#### Advanced CNN Applications
- **CNN for NLP** - Text classification with convolutions
- **CNN Visualization** - Understanding learned features

---

### Level 3: Advanced Architectures

#### Transformers
- **DistilBERT** - Efficient transformer models
- **Fine-tuning Strategies** - Transfer learning approaches
- **Feature Extraction** - Using transformers as feature extractors

#### Autoencoders
- **Basic Autoencoders** - Dimensionality reduction
- **Convolutional Autoencoders** - Image compression
- **Variational Autoencoders** - Generative models

#### Specialized Applications
- **Metric Learning** - Siamese networks
- **Ordinal Regression** - Ordered classification
- **Normalization Layers** - Training stability techniques

---

### Level 4: Training Techniques

#### Data Augmentation
- **AutoAugment** - Automated augmentation strategies
- **Custom Augmentation** - Domain-specific techniques

#### Optimization Tricks
- **Cyclical Learning Rates** - Learning rate scheduling
- **Gradient Clipping** - Training stability
- **Batch Size Optimization** - Performance tuning

#### Cross-Validation
- **K-Fold Cross-Validation** - Robust evaluation
- **Stratified Sampling** - Balanced datasets
